### IAM 정책 적용 방식
-----
1. 한 주체에 다양한 정책을 동시에 적용 가능 (예) 그룹 정책 + 사용자 개인 정책 + SCP + 권한 제한 등)
2. 권한 적용 시 다음 규칙에 따라 평가
   - 명시적인 Deny는 언제나 우선 적용
   - 명시적으로 Allow 하지 않는 경우 : 묵시적으로 Deny
   - 명시적으로 Allow가 있다면 권한 획득
3. 이외에 적용 순서 규칙에 따름
4. IAM 정책 적용 순서
   - 명시적 Deny : 권한 없음
   - SCP 
   - 리소스 정책 : 존재하면 권한 허용
   - 자격 증명 정책
   - 권한 범위
   - 세션 정책 허용 : 되면 허용
