----
### AWS CloudShell
-----
1. 브라우저 기반의 사전 인증된 셸로, AWS Management Consonle에서 직접 시작 가능
2. AWS Console에서 바로 실행 가능한 Shell 환경 : 콘솔에 로그인한 IAM 유저의 권한을 기반으로 미리 인증되어 있음
3. 무료이며, Bash / PowerShell / Z Shell 환경 선택 가능
4. 기본적으로 설치되어 있는 다양한 툴 / 유틸리티 활용 가능 (git, make, wget, zip / AWS CLI, AWS ECS-CLI, AWS ElasticBeanstalk 등 기본 설치)
5. 기본적으로 여러 프로그래밍 언어 환경 제공 (Node.js, Python, .net(PowerShell) 등)
6. 세션 기반, 즉, 각 세션이 종료되면 직접 설정한 환경과 구성은 리셋 (단, 1GB의 영구 스토리지 활용 가능)

-----
### 세션 (Session)
-----
1. 두 가지 제약
   - 마우스나 키보드 입력이 20 ~ 30분 동안 없다면 세션 종료 : 프로세스 실행은 입력으로 취급하지 않음
   - 약 12시간 동안 지속되었다면 종료

2. 리스타트 가능 : 몇 분 소요
3. 리전 당 최대 동시에 10개까지 세션을 동시에 사용 가능
4. 홈 디렉토리 삭제를 통해 깔끔하게 리셋 가능
   - 시스템 파일이 손상되었거나 문제가 생긴 경우 / 장애가 발생한 경우
   - 보안적 이유로 작업 내용을 정리하고 싶은 경우

-----
### 영구 스토리지
-----
1. 각 리전별로 1GB 영구 스토리지 활용 가능 : 더 큰 용량이 필요하다면 CodeCommit 혹은 S3 활용 가능
2. home 디렉토리에 위치 ($HOME)
3. 120일 동안 사용하지 않으면 자동 삭제 : 120일 안에 다시 활용하면 계속 사용 가능
4. KMS로 암호화

-----
### 컴퓨팅 및 네트워크
-----
1. 내부적으로 Amazon Linux 2023 기반의 컴퓨팅 환경(1vCPU, 2GB RAM)을 만들고, SSM Session으로 연동 : 내부적으로 브라우저와 WebSocket을 통해 연결 (보안적 허용 필요)
2. 네트워크
   - Out-Bound : 인터넷 액세스 가능
   - In-Bound : 인바운드 포트 활용 불가능 (Public IP 부여 불가능)

-----
### 보안
-----
1. IAM 인증을 활용하여 권한 제어
2. 일정 시간이 지나면 세션이 자동으로 종료
3. Safe Paste 기능이 기본적 활성화 : 악의적 스크립트 내용의 복사 / 붙여넣기를 막아주는 기능
4. CloudTrail로 기록 확인 가능 : 작업 내역에 대한 확인은 불가능
5. 외부 인터넷 액세스가 가능하므로 데이터 전송 등 리스크 존재 : VPC 모드 지원, 즉, VPC 안에서 CloudShell을 프로비전해 이용 가능
   - 외부 인터넷에 대한 통제 가능
   - 단, VPC 엔드포인트 프로비전 및 업로드 / 다운로드 기능 사용 불가능 등의 기능 제약 발생

-----

7. 업로드 가능 : 업로드 후, dir
8. 설치 목록 확인 : ll /usr/local/bin
9. 리셋 가능 : 작업 - 다시 시작
10. 영구 스토리지 삭제 : 작업 - 삭제
