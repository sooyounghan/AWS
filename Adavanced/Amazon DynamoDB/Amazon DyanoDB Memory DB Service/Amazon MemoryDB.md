### Amazon MemoryDB
-----
1. Valkey 및 Redis OSS 호환성 및 내구성을 바탕으로 초고속 성능을 제공하는 In-Memory 데이터베이스 서비스
2. Valkey, Redis OSS를 지원하는 AWS의 Memory DB 서비스
   - 메모리 DB를 DB로 활용하기 위한 서비스
   - Multi-AZ 및 Multi-Region 지원
   - 주로 매우 빠른 응답속도를 요구하는 애플리케이션 혹은 높은 동시성이 필요한 메인 DB로 활용

3. Microsecond 단위의 응답속도와 높은 Throughput, Multi-AZ 확장성 지원
4. Strong Consistency 모델 (백업 : Eventual Consistency)
5. 영속적 데이터 저장 지원
6. 스냅샷 기반 백업
