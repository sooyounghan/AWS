-----
### Application Load Balancer
-----
1. OSI Model Layer 7
   - Header, Cookie, Domain 이해 가능 : Header를 변경하거나 Domain 기반 라우팅

2. HTTP / HTTPS 프로토콜만 지원 : 지속적인 연결 없이 요청시에만 연결 수립
3. 다양한 규칙 기반으로 여러 대상 그룹 (Target Group)으로 분배 가능
4. IP 고정 불가능 : IPAM을 활용할 수 있으나 여기서는 논외
