-----
### Dedicated Host vs Dedicated Instance
-----
<div align="center">
<img src="https://github.com/user-attachments/assets/81f97238-7fa6-4e3c-8cf5-1206b9996af1" />
</div>

1. Dedicated Host
   - 인스턴스 간의 간섭을 배제하거나 보안 규정 등 이유로 사용
   - 기본 요금 + 사용 인스턴스 당 비용 지불

2. Dedicated Instance
   - 인스턴스 간 간섭을 배제하거나 보안 규정 등 이유로 사용
   - 라이센스 이슈와 인스턴스 간 Latency을 줄이기 위해 사용 : 자신의 라이센스 활용 가능
   - 호스트 비용 지불
   - 이후 호스트를 어떻게 이용하는지는 사용자 마음대로 가능
   - 인스턴스 개수 제한 없음 (정해진 한도 내)
