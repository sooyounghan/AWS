-----
### AWS Trusted Advisor
-----
1. AWS의 현재 상태를 기반으로 AWS를 최적으로 운용하기 위한 권장 사항 제공
2. 카테고리
   - 비용 최적화 : 예약 인스턴스(RI), 사용 안하는 EC2 등
   - 성능 : EBS의 IOPS, CloudFront 사용 등
   - 보안 : 보안 그룹 포트, IAM 암호 로테이션 등
   - 내결함성 : 백업 및 다중화 (RDS의 Multi-AZ, EC2 가용 영역 분산)
   - 서비스 한도 : AWS 리소스의 한도 (예) EC2의 인스턴스 타입별 갯수)

3. AWS Support 티어 별로 다른 점검 숫자 : 기본 56개, Business Support 이상에서는 최대 482개 이상
