### AWS Budgets
-----
1. AWS 예산 사용 시에는 사용자 지전 예산을 설정할 수 있으며, 시간별 비용 / 사용량을 지속적으로 파악하여 비용이나 사용량이 임계값을 초과하면 신속하게 대응할 수 있음
2. AWS에서 발생한 비용과 사용량을 추적하고 대응하는 서비스
3. 사용자가 지정한 비용 이상으로 비용이 발생 시 대응
   - Action을 설정하여 리소스를 종료시키거나 신규 생성 방지
   - SNS 수신 가능 = 다양한 방법으로 Fan-Out 대응 (Slack, Teams, 자동 로직 적용 등)

4. 보고서 작성 가능 : 일일 / 주간 / 월간 단위로 해당 예산의 사용 현황 보고
5. 다운로드 가능
6. Organization 단위로 비용 측정 : 즉, 같은 Organization의 AWS 계정들에서 발생한 비용을 포함해서 측정

-----
### AWS Budgets 예산 설정
-----
1. 비용 에산 : 비용을 달러($) 단위로 측정하고, 지정한 비용 이상으로 증가 시 알람을 받을 수 있음
2. 사용량 예산 : AWS의 서비스 (EC2, DynamoDB, S3 등) 사용량을 모니터링하고 설정한 사용량 이상으로 사용 시 알람
3. Savings Plan 예산 : Savings Plan에 따라 커버되는 사용량 추적
4. 예약 예산 : 예약 인스턴스 등 예약 리소스의 사용량 추적

-----
### Action
-----
1. 예산 허용 범위 이상으로 비용이 발생하거나 발생할 것으로 예상되는 경우 트리거되는 조치
2. 세 가지 종류
   - IAM 정책을 특정 사용자 / 그룹 / 역할에 부여 (예) 더 이상 EC2 생성 금지)

### 기타 주의할 점
-----
1. 하루 최대 3번 업데이트 (약 8 ~ 12시간 주기)
2. 실제 알림 시점까지 지연시간 발생 가능 : 즉, 실제 의도보다 비용이 더 발생할 가능성 존재
3. 요금에는 환급금, 크레딧, 세금 등을 포함하거나 제외 가능 : 크레딧이 있을 경우 실제 비용 청구에 반응할 때 유용
