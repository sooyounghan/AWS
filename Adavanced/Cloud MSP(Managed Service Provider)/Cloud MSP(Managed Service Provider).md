### 클라우드 사용 시 필요한 것들
-----
1. 아키텍쳐 설계
   - 신규 설계
   - 마이그레이션

2. 운영 : 모니터링, 장애 대응, 보고서 발행
3. 빌링 : 빌링 처리, 선입금, 비용 처리
4. 기타 : 기술 지원, 사용 사례 점검, 보안 점검

### MSP (Managed Service Provider)
-----
1. 클라우드 인프라 관리 서비스 제공 업체
2. 주요 역할
   - 컨설팅 : 아키텍쳐 설계 / 업데이트 / Best Practice 지원 등
   - 마이그레이션 지원
   - 운영 관리 / 티켓 처리
   - 빌링 관련 지원
   - 교육 지원
   - POC 지원
   - 기타 클라우드 운영 / 관리에 필요한 모든 서비스 제공

3. AWS 사용 계획 → 도입 → 운영 → 업데이트 과정을 같이 수행 및 성장
4. 몇몇 지원 사업의 경우 MSP를 필수적으로 끼고 지원 필요
5. 집중하는 분야가 따로 존재 (예) 엔터프라이즈 vs 스타트업)
6. 기타 여러가지 혜택 : 파트너사 행사 / 이벤트 지원
7. 규모의 경제

### AWS의 MSP 평가 / 관리
-----
1. AWS에서 직접 MSP의 퀄리티를 평가 / 관리
2. 주기적인 감사 및 평가(외부기관) : 매년 + 3년마다 Full Audit
3. 주요 지표
   - 세일즈 / 프레젠테이션 능력
   - 고객 성장
   - 기업 건전성 및 영속성
   - 내부 보안 / AWS 관련 보안
   - AWS 기술에 대한 이해
   - 기타 파트너 수행 능력

### MSP의 단점
-----
1. 추가 비용 발생 (보통 일정 %)
2. 경우에 따라 빌링 서비스 이용 불가 (예) Cost Explorer) : 자체적인 빌링 시스템을 갖춘 MSP 존재
3. 경우에 따라 Organization, SCP 이용 불가 : Payer 계정으로 묶어 사용은 가능한 경우도 있지만, SCP 사용 불가
4. 일정 단계 이상 서포트 티어 요구 있을 수 있음
