### 임시자격증명 활용
-----
1. 하드코딩 대신 필요할 때 인증을 거친 후 임시자격증명 발급 : 발급 받은 자격증명을 원하는 주체에 전달 후 활용
2. 갱신이 필요하면 다시 인증 요청
3. 활용 예시
   - EC2 IAM 역할 부여 (자동 갱신)
   - 다른 주체에게 잠시동안 권한을 비려주는 패턴

4. 예시) S3 파일 업로드 시 임시 크레덴셜 활용
