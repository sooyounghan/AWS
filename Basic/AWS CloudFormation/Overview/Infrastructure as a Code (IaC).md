-----
### Infrastructure as a Code (IaC)
-----
1. 클라우드에서 인프라를 코드로 관리하는 방법
2. 장점
   - 항상 일관된 아키텍쳐 구현 : 휴먼 에러 배제할 수 있음
   - 재사용성
     + 일정 단위의 모듈로 만들어 다양한 프로젝트에서 재사용 가능
     + 인프라의 구성을 다른 사람과 공유하거나 복제 가능

   - 쉬운 관리
     + 리소스의 변경 및 이력 추적
     + 일괄 삭제
     + Git 등을 통해서 형상 관리 등
